# AI-Scarcrow
AI Scarecrow is a smart farming solution that detects animals in real time using computer vision and Python. When an animal is identified, it triggers sound alerts to scare them away, protecting crops. This project showcases practical AI applications in agriculture, reducing crop damage and minimizing the need for constant human monitoring.
